# Catbird Linux Scripts
=======================

Scripts, configurations, and tools providing efficient, powerful, yet user friendly functions in Catbird Linux.  They work on most Linux with Bash and commonly installed utilities.

_Everything here is in Catbird Linux versions 3 and earlier. [Catbird Linux version 4](https://github.com/ab9il/catbirdlinux/) is an image-based operating system which will use some, but not all, of these tools._
